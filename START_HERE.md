# Start Here

A practical path for working with a new or unfamiliar codebase.

## 1. Build a shared model

Open [Onboard](prompt-library/01-onboard.md) and [Understand](prompt-library/02-understand.md). Use them to map architecture, locate behavior, and inspect history before editing.

## 2. Turn discovery into a plan

Use [Plan](prompt-library/03-plan.md) to scope files, edge cases, and acceptance criteria. Keep the change small enough to verify.

## 3. Build with a reference

Use [Implement](prompt-library/05-implement.md) or [Prototype](prompt-library/04-prototype.md). When possible, point to an existing internal pattern rather than inventing a new one.

## 4. Verify before you ship

Use [Test](prompt-library/06-test.md), then [Review](prompt-library/08-review.md). Finish with [Git](prompt-library/10-git.md) or [Release](prompt-library/11-release.md).

## When production is involved

Start with [Incident](prompt-library/15-incident.md) and [Debug](prompt-library/09-debug.md). Preserve evidence, make the smallest safe change, and record the follow-up.

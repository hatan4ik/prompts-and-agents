# Repository Guide

## Read this repository in this order

1. [Start Here](START_HERE.md) — a practical operating sequence.
2. [Claude Code Prompt Library](PROMPT_LIBRARY.md) — 52 prompts in direct Markdown.
3. [Agent Ecosystem](AGENT_ECOSYSTEM.md) — choose the right upstream project for the job.
4. [`upstreams/`](upstreams/) — source snapshots when you need implementation detail.

## Layout

```text
START_HERE.md          practical learning path
PROMPT_LIBRARY.md      human-readable prompt index
prompt-library/        direct Markdown prompt collections
AGENT_ECOSYSTEM.md     framework and collection guide
upstreams/             pinned source snapshots
sources/               provenance and commit pins
```

The repository prioritizes reading paths and direct examples. The automated importer exists only to keep the source snapshots reproducible.
